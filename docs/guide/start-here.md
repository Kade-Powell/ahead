# Start here

AHEAD is a native code editor with a file explorer, editor tabs, an interactive terminal, and an Agent and Threads area. Open **Help > AHEAD Guide** or the help icon in the status bar whenever you need these instructions. The guide is bundled with the app, so it works while you are offline and while another project is open.

## Open a project

1. Choose a project folder when AHEAD opens. The folder becomes the workspace root.
2. Use the Explorer on the left to open a file. If it is hidden, use **Cmd+B** on macOS or **Ctrl+B** elsewhere.
3. Open Settings with **Cmd+,** or **Ctrl+,**. On first use, set a model connection if you want the built-in agent. File editing and the terminal do not need a model.

The left activity icons switch between Explorer, Source Control, Tasks, and Language Servers. The Command Palette calls the Explorer action **Files Explorer** and opens the **Extensions** gallery. The central tabs hold files, Search, Problems, Settings, Extensions, and this guide. The bottom dock holds terminals and the debugger. The right dock holds the conversation and Threads list. Hover an icon to see its action and shortcut.

## Find an action

Open the Command Palette with **Cmd+Shift+P** or **Ctrl+Shift+P**; **F1** also works. Type part of an action, use the arrow keys, and press **Enter**. Press **Escape** to leave without running anything. For a file, **Cmd+P** or **Ctrl+P** is faster.

## What the guide covers

Choose a topic on the left for files and editing, Search and Git, terminals and debugging, agent sessions, connections and settings, voice and sharing, or shortcuts. Instructions describe the current UI. A section marked **Partial** has a visible control or underlying code whose complete workflow is still being verified. A section marked **Unavailable** is planned but cannot be completed in the app yet.

Your project can contain private `.ahead/` state. Keep credentials in private settings, review files before sending them to an agent, and use a disposable project when trying a new workflow.
